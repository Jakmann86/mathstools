Key idea: The mean uses every value in its calculation, so one extreme value drags it up.
The median only cares about position — it's resistant to outliers.
The mode only counts frequency — the outlier doesn't affect it at all.

DriverMean (s)SD (s)
Hamilton

💡 Formula: Number of SDs = (value − mean) ÷ SD  |  More than 2 SDs = potential outlier
✍️ ___ SDs from the mean. Unusual? Yes / No
2.5 SDs — Yes, unusual
(96.8 − 91.5) ÷ 2.1 = 5.3 ÷ 2.1 ≈ 2.5
More than 2 SDs from the mean → potential outlier.

Question 13 of 13
💬 Quick Check
True or False?
A. "The mean is always the best measure of centre."
B. "A small standard deviation means the data is tightly clustered around the mean."
C. "Shoe size is quantitative discrete."
D. "If a value is 3 standard deviations from the mean, it is likely an outlier."
✍️ Write T or F for each
A
False
B
True
C
True
D
True
A: False — in skewed data, the median is better (we just saw this with books!)
B: True — small SD = less spread = more consistent (like Verstappen)
C: True — shoe sizes are specific values: 36, 37, 38… not 37.4
D: True — 3 SDs from the mean is very rare in most distributions
